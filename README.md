# 📘 React Client-Side Routing

A simple React application demonstrating **client-side routing** using `react-router-dom`.  
This project includes multiple pages (`Home`, `About`, `Contact`, and `NotFound`) with smooth navigation, without refreshing the browser.

---

## 🚀 Features
- **React Router v6** for navigation  
- **Reusable Components** for pages  
- **NotFound Page** for invalid routes  
- **Clean & Responsive UI**
